# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Host

Серверная граница исполнения, которая предоставляет клиентам авторизованный доступ к Durable, но не передаёт им владение исполнением или хранилищем.

## Session owner

Единственный действующий владелец исполнения и записи конкретной Durable-сессии, независимый от числа подключённых клиентов.

Потеря клиентского соединения не освобождает это владение. Отсутствие ответа владельца само по себе не даёт другому процессу права захватить его хранилище.

## Sealed release

Зафиксированный набор исполняемых файлов, зависимостей и артефактов Host, целостность которого проверяется по manifest перед включением.

Проверка одного исходного файла или отдельной сборки не заменяет проверку этого набора.

## Data/native parity

Сохранность прежних идентичностей, конфигураций, истории, состояния задач и native-возможностей при замене Host.

Не означает восстановления внешних MCP-подключений.

## MCP parity

Сохранение прежде предложенного набора внешних MCP-инструментов в соответствующих разговорах после изменения Host.

Это сравнение каталогов, а не доказательство успешного исполнения каждой операции внешнего сервера.
