# Проверить кандидатов после исследования

Назначение по Diátaxis: инструкция для будущих проверок. Эксперименты предложены в исследовании, но не выполнялись. Эта редакторская фаза не разрешает запуск runtime. Модели, внешние providers и инфраструктура потребуют отдельной авторизации.

[Объяснение выбора](CLOUDFLARE-AGENTRUN.md) содержит рекомендацию. [Справочник кандидатов](REPORT-REFERENCE.md) содержит закреплённые commits, исходники и ограничения доказательств.

До запуска физически исключите доступ стенда к рабочим базам и секретам. Ограничение относится также к родительскому процессу и дочерним процессам. Одной замены `HOME` недостаточно.

## 1. Проверить принятие запроса AgentRun при аварийной остановке

1. Закрепите artifact/commit и совместимый набор версий Pi.
2. Используйте faux model. Оборвите сервер после native submit, но до сохранения `.idempotency.json`.
3. Повторите прежний request ID после перезапуска.
4. Считайте submissions, а не только строки transcript.
5. Если возникает дубликат, добавьте долговечный слой принятия и подтверждения запроса до принятия кандидата.

Это fault-injection для проверки неопределённой отправки, а не разрешение слепо повторять внешние эффекты.

## 2. Проверить восстановление Cloudflare и транспортный адаптер

1. Используйте локальный CF test runtime без живой модели.
2. Проверьте один Harness на session.
3. Проверьте сохранение requestId при переподключении.
4. Проверьте alarm после eviction.
5. Подключите минимальный наш транспортный адаптер.
6. Проверьте обработку неизвестного результата без нового requestId.
7. Отдельно подтвердите завершение задачи. Изменение статуса само по себе недостаточно.

## 3. Проверить совместимость полного профиля

1. Создайте две независимые sessions.
2. Зарегистрируйте native definitions до open.
3. Выполните memory/MCP binding до resume.
4. Проверьте revoke во время ожидания.
5. Проверьте drain, reload и повторное открытие.
6. Проверьте путь input image от DTO до model request.
7. Проверьте сценарии terminal, BB и iii.

До этих проверок соответствие полному профилю не подтверждено. Экспериментам не нужны production-базы или credentials пользователя. Начните с принятия запроса и восстановления, а не с оформления console.
