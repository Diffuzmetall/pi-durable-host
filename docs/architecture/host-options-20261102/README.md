**Начните со [сводного вывода](SUMMARY.md).** В нём указано, какой вариант проверить первым и когда замена backend оправданна.

## Граница результата

Исследователи не запускали кандидатов и не меняли рабочий Host. Таблицы описывают исходники, а не результаты сквозных проверок.

Ни один кандидат не принят как готовая замена. Переход, перенос баз и установка пакетов в этой работе не выполняются.
