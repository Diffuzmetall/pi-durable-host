## Различие источников

Исходник подтверждает наличие механизма. README передаёт заявление автора. Issue сообщает о наблюдении, которое требует отдельного воспроизведения.

Ни один такой источник не заменяет запуск нашего профиля на кандидате. В частности, найденный recovery-тест не означает, что этот тест прошёл в данной работе.

> 🧠 **From Hindsight memory (Component map)** — память описывает SDK и адаптеры как клиентов единого серверного владельца исполнения. Эта граница сверена с текущей картой Host. Исторические заявления о готовности не использованы как подтверждение текущей работоспособности.

CodeGraph не дал пригодного результата для части исследуемых checkout. Исследователи использовали навигацию по исходникам. Новые индексы автоматически не создавались.

## Редакторская проверка

Ко всем Markdown-документам архитектурного пакета применены `asd-ste100-ru`, `technical-writing` и `unslop`. Документы разделены по назначению: объяснение, справочник или процедура.

Проверка `utr_check.py` оценивает формальные ограничения текста. Она не заменяет проверку смысла и не означает сертификацию по ГОСТ.

Блоки кода, Mermaid, commit IDs и адреса источников сохраняются при редактуре. Исторические логи не переписываются под новый стиль.

Проверка структуры пакета находится в [`../verify.py`](../verify.py). Её команда:

```sh
python3 docs/architecture/verify.py
```

Скрипт проверяет локальные ссылки, блоки Markdown и отдельные утверждения о текущем Host. Он не исполняет код кандидатов.

Проверка собранного пакета охватила 32 Markdown-файла, 307 локальных ссылок и пять Mermaid-блоков. Проверки структуры Markdown и утверждений об исходниках завершились успешно.

`utr_check.py` не обнаружил нарушений в 32 файлах. Он также выдал рекомендации по стилю. Технические термины и оговорки сохранены там, где механическая замена ухудшает точность.

Сравнение с копией до редактуры подтвердило сохранность блоков кода и внешних Markdown-ссылок. `git diff --check` завершился успешно. Ограниченный поиск шаблонов секретов в Markdown не нашёл совпадений.
