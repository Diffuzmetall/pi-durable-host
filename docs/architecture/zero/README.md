# Наш Host на durable-zero: внешние пакеты без изменения Zero

[Весь архитектурный пакет](../README.md) · [Как Host устроен сейчас](../MAP.md)

Дата: 2026-11-02. Статус: **исследование и рекомендуемая архитектура, не реализованный переход**. Внешняя композиция C — вариант для обсуждения, не окончательно утверждённый план миграции.

## Ответ

Наши расширения можно вынести в отдельные пакеты, не меняя исходники Zero. В `v0.7.0` уже есть два входа: обычные Pi Extensions и `openDurable({ builtins })` для регистрации native definitions.

Но **упаковка расширений не делает готовый `openDurable()` эквивалентом нашего полного Host**. Не хватает управления запуском до `resume`, передачи защищённого execution environment, commit-authorization и доступа к extension runner для полного UI/reload. В README эти необходимые нам контракты не определены.

**Рекомендуемый вариант для полного профиля: внешний пакет интеграции использует экспортируемые компоненты Zero и существующую native-композицию нашего Host.** Zero остаётся неизменённой зависимостью; единственный движок выполнения — Pi Durable. Мы владеем сборкой и жизненным циклом runtime, но не копируем scheduler, transactions или recovery.

Это важное различие: **Zero как библиотечная основа — да; готовый `DurableEngine/openDurable` как единственный обязательный способ запуска полного профиля — пока не доказано**. Если нужен именно второй вариант, полное сохранение текущих требований на исследованной версии заблокировано. Нельзя скрыть это за названием adapter.

## Границы поручения

- Первый клиент — наш терминал. Архитектура предусматривает BB и iii, но их подключение сейчас не выполняется.
- Zero не патчится, не форкается, не подменяется через monkey-patching, private imports или loader aliases.
- Отдельный пакет не означает отдельный процесс или независимость от версии native SDK.
- Не разрешены production-переход, чтение рабочих БД/секретов, публикация пакетов, новые агенты или изменение текущей DeLM-доски.
- [ISA](../../../ISA.md), [текущий PLAN](../../host-design/PLAN.md), [DM1](../../host-design/hot-update/DURABLE-MODULE-PLAN.md) и [предыдущая архитектура](../../host-design/runtime-architecture-20261102/ARCHITECTURE.md) сохранены. Этот каталог — companion research, не команда изменить выполняемый план.

## Что проверено

Свежий изолированный запуск штатных тестов `BuiltinExtensionRegistry`: **3 PASS / 0 FAIL**. Проверены регистрация, отказ при повторном ID и обратный порядок teardown. Source и поставляемый bundle показывают публичный экспорт точек интеграции.

**Не проверены:** полный import/install closure, запуск Host на Zero, восстановление наших native extensions, UI roundtrip, BB/iii, hot reload и совместимость рабочих данных. Исследование не заменяет их приёмку.
