## Статические проверки документационного пакета

Для проверок без изменения пакета предусмотрены команды.

```sh
python3 docs/architecture/verify.py
python3 docs/architecture/zero/verify.py /path/to/clean/durable-zero-v0.7.0
```

Первый скрипт проверяет локальные ссылки, Markdown и перечисленные факты об исходниках. Второй дополнительно сверяет чистый Zero checkout с закреплённым commit, проверяет публичные exports и места подключения lifecycle. Оба скрипта не запускают Host, модели или SQLite. Импорты полного npm-пакета, рендер схем и производительность здесь не проверяются.

## Проверка состава публикации

Локальные шаблоны проверили новые и изменённые текстовые файлы на следующие данные.

- Приватные ключи, токены провайдеров и GitHub, JWT.
- URL с credentials и литералы credential-полей.
- Приватные email и имена узлов tailnet.

Найденное операторское имя узла скрыто. Оставшиеся совпадения, похожие на credentials, относятся к явным тестовым фикстурам и имени npm script `token`.

Это ограниченная проверка состава публикации. Она не является полным аудитом безопасности и не доказывает отсутствие любого возможного секрета. Production auth, config и DB для неё не читались. [STATUS.md](STATUS.md) содержит результаты статических проверок кода. Завершение commit или push не меняет FAIL на PASS.

Документация проверяется на наличие относительных ссылок, структуру Markdown и пять Mermaid-блоков. Четыре блока находятся в обзоре, один в карте исходников. Визуальная браузерная приёмка Mermaid не заявляется. SHA опубликованного Git-коммита определяет содержимое для сравнения, в отличие от изменяющейся рабочей копии.
