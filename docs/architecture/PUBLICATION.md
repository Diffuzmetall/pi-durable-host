## Проверка публикации

Новые и изменённые текстовые файлы проверялись локальными шаблонами на private keys, provider/GitHub tokens, JWT, credential-bearing URLs, литералы credential-полей, приватные email и tailnet hostnames. Найденный операторский hostname скрыт; оставшиеся credential-like совпадения относятся к явным тестовым фикстурам и имени npm script `token`.

Это ограниченная проверка состава публикации, **не полный security audit и не доказательство отсутствия любого возможного секрета**. Production auth/config/DB для неё не читались. Результаты статических проверок кода — в [STATUS.md](STATUS.md); завершение commit/push не меняет их FAIL на PASS.

Документация проверяется на наличие относительных ссылок, структуру Markdown и четыре Mermaid-блока. Визуальная браузерная приёмка Mermaid не заявляется. Для сравнения содержимого используйте SHA опубликованного Git-коммита, а не изменяющуюся рабочую копию.
