# Готовые задания для агентов

Выберите одно задание и вставьте его в свою coding-agent сессию. Задайте только нужные параметры; секреты не вставляйте в текст.

- [INSTALL](INSTALL.md): новая изолированная установка и настоящий результат.
- [CONNECT](CONNECT.md): подключение к существующему host.
- [CUSTOM_PROFILE](CUSTOM_PROFILE.md): свой native profile.
- [NEW_ADAPTER](NEW_ADAPTER.md): новый интерфейс поверх публичного API.

Это переносимые промпты, а не обязательные команды конкретного harness. У агента могут быть shell/files/browser tools, но нет подразумеваемого доступа к вашим production, GitHub, credentials или платным моделям.

Прочитайте [статус](../STATUS.md) перед запуском. Изменившаяся версия/контракт требует проверки текущих manifests и исходников; не подменяйте отсутствие capability несуществующим методом.
