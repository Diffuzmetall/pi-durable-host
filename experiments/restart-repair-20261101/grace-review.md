- Carol: завершите shared.initialize до resume любой сессии. Прежний Store.open выполняет initialize перед общим resume.
- Carol: закройте admission для create и остальных mutations при начале close. Проверки только runtime()/harness() недостаточно: create вызывает openAgent напрямую.
- Carol: учитывайте все начатые операции, включая create и openAgent, прежде чем освобождать shared/catalog/locks.
- Carol: повторный close должен возвращать общий результат закрытия. После начала close восстановление не должно запускать resume.
- Carol: объявляйте ready после bind, регистрации владельца и допустимого resume. Не запускайте второй initializer для той же session.
- Dave: optional readiness не заменяет серверный отказ unavailable/503. Старый клиент может не читать новое поле.
- Dave: сохраните авторизацию для каталога, metadata и ошибок. Ошибка одной сессии не означает отказ liveness.
- Frank: не освобождайте locks по timeout при незавершённом initializer. Сначала дождитесь начатых операций, затем закройте runtime и общие ресурсы.

- Eve: снимайте только transient submit error после авторитетной сверки. Сохраните настоящий attention, черновик и защиту от повторной отправки.
